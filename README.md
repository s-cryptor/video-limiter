# Video Limiter

Расширение для Google Chrome, которое считает, сколько времени вы смотрите видео во **всех вкладках**, и после исчерпания дневного лимита ставит видео на паузу и не даёт их запускать. По умолчанию лимит — **1 час в день**.

## Возможности

- Учитывает любой HTML5 `<video>` на любом сайте, включая видео во встроенных iframe (YouTube-плееры на сторонних сайтах и т.п.).
- Время считается по реальным часам: если видео играет в двух вкладках одновременно, за секунду засчитывается одна секунда, а не две.
- Не учитывает «фоновый шум»: беззвучное видео в неактивной вкладке (автоплей-реклама, превью) не считается просмотром. Пауза и буферизация тоже не считаются.
- Когда лимит исчерпан, все видео встают на паузу, полноэкранный режим закрывается, поверх страницы показывается сообщение. Повторно запустить видео не получится.
- Счётчик сбрасывается в полночь по местному времени.
- На иконке расширения показывается, сколько минут осталось.
- В popup задаются лимит в минутах и переключатель блокировки. Если блокировку выключить, время продолжает считаться.

## Установка

Расширение не опубликовано в Chrome Web Store, поэтому его ставят как «распакованное». Это стандартный способ, занимает пару минут.

### 1. Скачайте код

Через git:

```bash
git clone git@github.com:s-cryptor/video-limiter.git ~/video-limiter
```

Или скачайте ZIP на GitHub (**Code → Download ZIP**) и распакуйте его в любую постоянную папку.

> **Важно:** не удаляйте и не перемещайте эту папку после установки. Chrome загружает расширение прямо из неё, и без неё расширение перестанет работать.

### 2. Загрузите расширение в Chrome

1. Откройте в адресной строке `chrome://extensions`.
2. В правом верхнем углу включите переключатель **Режим разработчика** (Developer mode).
3. Слева появится кнопка **Загрузить распакованное расширение** (Load unpacked). Нажмите её.
4. Выберите папку `video-limiter`, в которой лежит `manifest.json` (не папку `src`!), и нажмите **Выбрать**.
5. В списке появится карточка **Video Limiter** с синей иконкой. Проверьте, что переключатель на карточке включён и нет красной кнопки **Ошибки**.

### 3. Закрепите иконку на панели

1. Нажмите на значок пазла 🧩 справа от адресной строки.
2. Найдите **Video Limiter** и нажмите на булавку 📌.

Теперь иконка всегда видна. На ней цифрой показано, сколько минут осталось на сегодня.

### 4. Перезагрузите открытые вкладки

Расширение начинает работать только на страницах, открытых **после** установки. Перезагрузите вкладки с видео (⌘R / Ctrl+R).

### 5. (Необязательно) Инкогнито

По умолчанию расширения не работают в режиме инкогнито. Чтобы лимит действовал и там, откройте `chrome://extensions`, нажмите **Сведения** (Details) на карточке Video Limiter и включите **Разрешить использование в режиме инкогнито**.

## Использование

### Настройка лимита

1. Нажмите на иконку Video Limiter на панели.
2. В поле **Дневной лимит, минут** введите нужное значение, например `30` или `90`. По умолчанию стоит `60`.
3. Нажмите **Сохранить**.

Новый лимит применяется сразу. Если увеличить лимит после блокировки, видео снова станут доступны.

### Что показывает popup

- **Просмотрено сегодня**: суммарное время просмотра во всех вкладках с полуночи.
- **Осталось**: сколько ещё можно посмотреть сегодня.
- Полоса прогресса синяя, а когда лимит исчерпан, становится красной.

### Бейдж на иконке

| Бейдж | Значение |
|---|---|
| синий, число (`45`) | осталось столько минут |
| красный `0` | лимит исчерпан, видео заблокированы |
| серый `off` | блокировка выключена, время только считается |

### Что происходит при исчерпании лимита

- Все играющие видео встают на паузу, полноэкранный режим закрывается.
- Поверх страницы появляется сообщение «Лимит видео на сегодня исчерпан». Кнопка **Закрыть** убирает сообщение, чтобы можно было пользоваться остальной страницей (читать комментарии и т.п.), но видео остаются заблокированными: при попытке запуска они сразу ставятся на паузу.
- В полночь по местному времени счётчик обнуляется, и видео снова доступны. Перезагружать страницы не нужно.

### Временно отключить блокировку

Снимите галочку **Блокировать видео после лимита** в popup и нажмите **Сохранить**. Время продолжит считаться, но видео не будут блокироваться. Чтобы полностью выключить расширение, используйте переключатель на его карточке в `chrome://extensions`.

## Обновление

Если вы ставили через git:

```bash
cd ~/video-limiter && git pull
```

Если через ZIP, скачайте новый архив и замените содержимое папки.

Затем откройте `chrome://extensions` и нажмите ⟳ (**Обновить**) на карточке Video Limiter, после этого перезагрузите вкладки с видео. Накопленное время и настройки сохранятся.

## Удаление

На `chrome://extensions` нажмите **Удалить** на карточке Video Limiter. После этого папку с кодом можно удалить.

## Если что-то не работает

- **Время не считается на сайте.** Перезагрузите вкладку: страницы, открытые до установки или обновления расширения, не отслеживаются. Убедитесь, что видео действительно играет со звуком или вкладка активна (беззвучное видео в фоне не считается).
- **На иконке нет цифры.** Цифра появляется после первого запуска браузера или первой секунды просмотра. Откройте popup или включите любое видео.
- **Красная кнопка «Ошибки» на карточке.** Нажмите её, чтобы увидеть текст ошибки. Чаще всего помогает ⟳ (**Обновить**). Если ошибка остаётся, создайте issue с её текстом.
- **Chrome предупреждает о расширениях в режиме разработчика.** Это нормально для распакованных расширений, предупреждение можно закрыть.
- **Не работает на некоторых страницах.** Chrome не пускает расширения на служебные страницы (`chrome://…`, Chrome Web Store).

## Как это работает

```
content.js (каждый фрейм)  --tick раз в секунду-->  background.js (service worker)
         ^                                                  |
         |                     { blocked }                  v
         +--------------------------------------  chrome.storage.local (usage)
                                                    chrome.storage.sync  (settings)
```

- `src/content.js` раз в секунду проверяет, есть ли во фрейме воспроизводимое видео. Если есть, отправляет `tick` в service worker и в ответ получает, заблокирован ли просмотр.
- `src/background.js` начисляет время, сохраняет его и обновляет бейдж.
- `src/lib/usage.js` содержит чистую логику: начисление времени, сброс по дням, проверку лимита.

## Ограничения

- Видео внутри закрытого (`closed`) Shadow DOM не обнаруживаются. Открытый Shadow DOM тоже пока не обходится.
- Учитывается только `<video>`. Flash, `<canvas>`-плееры и аудио не считаются.
- Расширение не работает на служебных страницах (`chrome://`, Chrome Web Store) и, если не разрешить, в режиме инкогнито.
- Это инструмент самоконтроля, а не родительский контроль: лимит можно поменять в popup, а расширение — отключить.

## Разработка

```bash
npm test
```

Тесты запускаются встроенным `node --test` (Node 18+), зависимостей нет. После правок нажмите ⟳ у расширения на `chrome://extensions` и перезагрузите вкладки.

Иконки (`icons/`) генерируются скриптом без зависимостей:

```bash
python3 scripts/generate-icons.py
```
